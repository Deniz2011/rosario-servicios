# Rosario Servicios

A web application developed with Django that connects customers with local service providers.

## About the Project

Rosario Servicios is a personal project created to strengthen my Python and Django skills by building a practical web application.

The platform allows users to publish service requests and enables professionals to browse available requests and submit proposals.

## Features

- Create service requests
- Browse available requests
- Submit service proposals
- Store data using SQLite
- Responsive web interface

## Installation

```bash
git clone https://github.com/Deniz2011/rosario-servicios.git

cd rosario-servicios

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
